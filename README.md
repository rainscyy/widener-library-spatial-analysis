# Harvard Widener Library

Dual-Classifier ML Analysis of Space

By Raine (Chunyu) Sha and Pengfeiyu Chen, Harvard SCI 6492 Quantitative Aesthetics, Assignment 3.

This interactive study compares independently trained arch / door and open / enclosed classifiers on the same architectural walkthrough. Scores are relative judgments between two classes, not objective measures of spatial openness.

## Acknowledgments

The classifier workflow builds on the course-provided Assignment 3 materials and scripts. Students curated their own training images, trained their classifiers, and developed this comparison and image-collection presentation.
